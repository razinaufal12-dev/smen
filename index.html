Pre, Post, H+7, dan Skor dalam persen (0–100). Skor adalah skor komposit yang menentukan peringkat.

Cara menghubungkan

Agar realtime, data harus ada di Google Sheets asli (Berkas → Simpan sebagai Google Spreadsheet), bukan file .xlsx yang hanya diunggah ke Drive.

Cara A: link langsung

  1. Bagikan sheet: Bagikan → Siapa saja yang memiliki link → Pelihara.
  2. Tempel link atau ID di kolom atas, klik Hubungkan. Tersimpan otomatis di browser ini.

Cara B: Apps Script (paling andal)

  1. Di Sheets: Ekstensi → Apps Script, tempel kode di bawah.
  2. Terapkan → Deployment baru → Aplikasi web, akses "Siapa saja".
  3. Tempel URL berakhiran https://script.google.com/macros/s/AKfycbzUd9AyF-0Nl0v19HUui8QV7d8gzczLbsQ7j9YCtN_NRLKHMGZDEvnCxmVVhaqIu8l9/exec di kolom atas, klik Hubungkan.
function doGet() {
  const o = {};
  SpreadsheetApp.getActiveSpreadsheet().getSheets()
    .forEach(s => o[s.getName()] = s.getDataRange().getValues());
  return ContentService.createTextOutput(JSON.stringify(o))
    .setMimeType(ContentService.MimeType.JSON);
}

Cara C: file Excel di komputer

Chrome atau Edge di komputer. Halaman mengecek file tiap 3 detik, jadi simpan (Ctrl+S) setelah mengisi.

Nama tab harus persis: . Susunan kolom tiap tab sama dengan tab K3.

Cara menghitung peringkat D–S

1. Skor tiap tahap (digabung dari semua sesi, bukan rata-rata persen):
Skor = Σ benar ÷ Σ soal × 100

2. Retention rate (sesi yang punya Post dan H+7):
H+7 ÷ Post × 100, maksimum 100

3. Gain ternormalisasi (sesi yang punya Pre dan Post):
(Post − Pre) ÷ (100 − Pre) × 100, minimum 0

4. Skor komposit:
Σ(bobot × komponen) ÷ Σ bobot yang tersedia

  • Baris dihitung hanya bila "Benar" terisi.
  • Komponen yang belum ada dibuang, bobot sisanya dinormalkan.
  • Peringkat S wajib punya data H+7, tanpa itu mentok di A.
  • Tanpa Post-test, mata kuliah belum diberi peringkat.
  • Peringkat keseluruhan memakai rata-rata komposit mata kuliah yang sudah dinilai.
